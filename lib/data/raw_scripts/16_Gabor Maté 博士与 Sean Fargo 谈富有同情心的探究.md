# Gabor Maté 博士与 Sean Fargo 谈富有同情心的探究

**来源**: 爬虫抓取 (https://mindfulnessexercises.com/podcast-episodes/dr-gabor-mate-on-compassionate-inquiry-with-sean-fargo/)

## 引导文案

我们每个人都渴望被看到、被听到、被爱。怀着好奇心和同情心探究我们的经历，让我们面对长期忽视的旧痛和强烈情绪，如果我们在当下、在与他人的关系中感到身体安全，这可以带来治愈。

通过富有同情心的探究方法，加博尔·马特博士教导治疗师、咨询师和个人发现支配我们生活的无意识动力，并摆脱这些习惯。

在本集中，嘉宝和肖恩讨论了同情心探究与我们通过正念练习学到的善良、非评判性好奇心之间的关系，构成同情心探究过程的五个层次的同情心，以及为什么被触发并不总是一件坏事，尤其是在富有同情心、善良意识的安全容器内。

作为正念练习者，我们指导他人留在当下。怀着关爱的好奇心探索感觉、想法或情绪是保持当下的一种方式。但如果我们不是训练有素的治疗师，引导我们自己或我们的学生去调查“为什么”而不是“什么”是否安全？加博说是的。如果我们抱着关心好奇的态度，那么探索我们当下表达之外的痛苦就没有什么危险。

“如果你抱有所谓的‘关爱好奇心’的态度，就不会有太大危险。你只是好奇。我不太害怕触发别人，或者让人们走上错误的道路。[...]我只是不认为这那么复杂或那么危险。而且只要你能保持所谓的关爱好奇心，我认为你就相当安全。”

我们小时候养成的习惯，甚至是抑制愤怒、抑郁或自我厌恶，都是有充分理由的。曾经，这些行为保护了我们并帮助我们生存。通过富有同情心地探索我们的感受，无论它是什么，我们最终都会被引导对我们的价值有同样的基本理解。 

“它的本质很简单，那就是，无论你感觉如何，你内心的一切都不是出于错误的原因。关于你的一切都是有充分理由出现的。所以，抑郁症；嗯，抑郁症的存在是有充分理由的，它帮助你生存……甚至你可能经历的自我厌恶也是有充分理由的。因此，方法就是对一切都感到好奇。我们甚至可以带着富有同情心的好奇心来对待自我厌恶。”

最基本的层面是理解当某人受苦时，我们也会受苦。当我们好奇地探索时，我们认识到，没有一个原因会导致他人的痛苦不存在于我们自己的内心。通过以自我慈悲来面对这个真理，我们也可以反映出他人治愈所需的慈悲心。

“其他人身上没有什么不是我身上的……这就是重点，我们都和其他人一样……当你探索这些判断时，你会发现你到底有多像你所判断的那个人。一旦你有了认可的同情心，你就不再在上面，他们在下面，你在看不起他们，不。这是两个人，平等地参与。” 

如果我们真的想帮助人们康复，我们必须效仿我们希望他们能够向自己提供的同情心。但我们有多少次看到苦难，并以判断而非无条件的爱来回应？通过扩大我们自己的同情心的能力，我们能够看到我们每个人内心的真实本性。我们成为受苦者的一面镜子，反映他们无限的潜力，而不是他们当下的功能障碍。 

“当你看到一个受苦的人时，也就是说，当你看到另一个人时，你只看到他们的痛苦和他们的功能障碍，这是他们对痛苦的反应，他们的防御和他们的反应，还是你看到他们在这一切之下的完美——真实的自我？……现在，不用说，如果你要成为一面镜子，猜猜你要做什么？你将不得不做很多自我清洁。”

加博尔通过探索与肖恩的时刻来展示富有同情心的探究如何发挥作用。两人展示了通过使用镜像创造安全空间的魔力、在安全空间中脆弱的力量，以及富有同情心的探究的温和过程如何揭示旧有的、模式化的信念和行为。 

“如果我能为你塑造这种同情心，那么在某个时刻，你就能开始为自己塑造这种同情心。所以，这不是一个扔掉东西或解决一切问题的问题，而是一个暗示一种富有同情心的探究态度的问题。同情心意味着你能够不带判断地接受它，好奇心意味着你想找出它为什么在那里。无论是疾病、感觉、反应还是其他什么，都是如此。”

作为正念教师，我们知道让学生在探索自己的痛苦和不适时感到安全非常重要。首先是在提出问题之前征求许可，并反复将这一过程视为邀请，而不是指令。让与你一起工作的人带头，并询问他们希望从交流中得到什么。注意我们自己一直存在的议程以及我们身体中存在的紧张情绪非常重要。 

“你不能制定议程。我的意思是你可以，但这会妨碍你。如果你为另一个人制定了议程，你首先会看到他们来到你办公室的原因是因为在他们生命中的某个时刻，有人为他们制定了一个议程，该议程与他们的需求无关，但与议程所在的人的需求无关。所以，如果他们出现与你一起工作，而你为他们制定了议程，你猜怎么着？你把他们放回到了他们原来的处境中。第一名。”

“当你和某人一起工作时，如果你内心有任何紧张，那就是你自己的问题。所以我总是教我的学生，只要有紧张，就需要关注。因为当你和别人一起工作时，我们会说些什么，但人们实际上会在深层次上进行充满活力的交流，即使不是有意识的。如果你内心有紧张，你就会把它传递给你的客户。”

避免触发因素在正念圈子中已经变得无处不在。但帮助人们避免痛苦并不是富有同情心；而是帮助人们避免痛苦。帮助他们克服本来可以避免的痛苦是富有同情心的。加博尔用一个比喻来解释为什么被触发本质上并没有什么问题，特别是在一个富有同情心、关怀和安全的空间里。事实上，当某人被触发时，这可能是一个更深入地探索一个人的反应性的机会。 

“你想做什么，专注于那个小小的触发器，或者你想看看你的身体里携带着你一生都携带的弹药和爆炸物吗？所以触发器我不太担心。并不是我故意这样做，也不是说我没有责任去尊重、正念和富有同情心，然后呈现出来，是的，触发器本身就是进入一个人内心生活的真正有趣的入口。”
