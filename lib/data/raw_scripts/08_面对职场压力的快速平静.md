# 面对职场压力的快速平静

**标签**: 职场, 快速减压, 情绪急救
**时长**: 约 3 分钟

## 练习准备
可以在办公桌前进行。将椅子拉近，双脚平踩在地板上，感受脚底与地面的接触。双手可以自然放在大腿上。如果是开放办公区，可以戴上降噪耳机。

## 引导文案

在忙碌的工作中，你可能刚刚经历了一次紧张的会议，或者收到了一个令人焦虑的消息。
现在，按下暂停键。给自己三分钟的时间，只需三分钟。

（停顿3秒）

如果你觉得安全，请闭上眼睛；如果不行，只需柔和地注视着前方的一个固定点。

深吸一口气，感受空气填满你的胸膛。
然后，用力地、长长地呼气，可以通过嘴巴呼出，就像把所有的压力叹出来一样。

再来一次，深深地吸气，吸入清新的空气。
缓慢而彻底地呼气，释放掉肩膀上的重担。

（停顿5秒）

现在，把你的注意力带到你的双脚。感受脚底板紧紧贴着地面。
无论上面的思绪有多么混乱，地面始终稳固地支撑着你。
把所有的注意力都集中在脚底这几平方厘米的接触面上。感受那种坚实和稳定。

（停顿8秒）

在职场中，我们常常感到事情已经失控，或者要求远远超出了我们的能力。
承认这种压力。告诉自己：“我现在感到有压力，这是很正常的反应。”
不要去对抗这种感觉，允许它存在，但不要让它控制你。

（停顿5秒）

想象你的呼吸是一个锚。当外界的风浪试图把你卷走时，每一次吸气，每一次呼气，都把你紧紧地固定在当下。
外界的任务依然存在，但你的内心可以有一片不被打扰的安静海域。

（停顿8秒）

最后做一次深呼吸。
吸气，将清晰和专注吸入体内。
呼气，释放掉不必要的恐慌。

当你准备好时，动动手指，慢慢睁开眼睛。带着这份重新找回的平静与清晰，回到你的工作中。你完全有能力处理好接下来的事情。
