# 想要快乐的意图

**来源**: 爬虫抓取 (https://mindfulnessexercises.com/intention-to-be-happy/)

## 引导文案

照顾自己慈心练习可以帮助你以友善的方式回应自己的内心。不幸的是，我们的思想并不总是按照我们想要的方式行事，身体可能会感到不适。慈心冥想鼓励我们以关怀和温柔的心去面对这些经历。这有助于我们在练习和日常生活中看得更清楚。在慈心练习中，你不是在邀请外界的东西；你是在调整关怀和爱的能力。以舒适的姿势坐下，轻轻地闭上眼睛。从一开始，就尝试将仁慈带入练习中。友善地思考身体。聆听它，看看是否可以移动以变得更舒服。

你不想睡着，但你可以让自己在这个练习中更加放松。首先要认识到你自己想要快乐的愿望。不要深究那些可能会让你快乐的故事。找到对自己轻松和舒适的自然愿望。试着对自己说，“是的，我想要快乐。”带着这个意图，开始给自己提供慈爱的短语。当你在脑海中提供这些短语时，慢慢地说出来。与单词背后的意图联系起来，即使你此刻不要完全感受到它们。使用这些短语：愿我快乐。愿我健康。愿我安全。愿我轻松。
