# 肖恩·法戈的感恩冥想

**来源**: 爬虫抓取 (https://mindfulnessexercises.com/podcast-episodes/a-thanks-giving-meditation-with-sean-fargo/)

## 引导文案

感恩让我们的心胸开阔，让我们的生活更加充实，让我们体验到更多的满足与平静。在这个引导冥想中，肖恩·法戈邀请我们注意我们此生最看重的是什么。然后我们特意表示感谢。表达我们的感激之情有助于让我们认识到当下这一刻的珍贵。 

感恩有能力将我们生命中的每一刻转化为一份礼物，即使是我们一开始可能认为是消极的。那些懂得感恩的人不太可能认为事情是理所当然的，而更有可能以关怀、体贴和慷慨的方式行事。 

在一个安全、安静的地方聆听，在那里你可以相对不受干扰，并聆听感恩的力量。
